# Sprint 3 — Manipulação e Limpeza de Dados

Projeto desenvolvido durante o bootcamp de Data Analytics da TripleTen.

## Objetivo

Analisar dados da Instacart para identificar padrões de comportamento dos clientes e preparar os dados para análises futuras.

## Descrição

Neste projeto foram realizados:
- limpeza e pré-processamento de dados;
- tratamento de valores ausentes e duplicados;
- análise exploratória de dados;
- criação de gráficos e visualizações;
- análise de hábitos de compra dos usuários.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Datasets utilizados

- instacart_orders.csv
- products.csv
- order_products.csv
- aisles.csv
- departments.csv

## Arquivos

- notebook.ipynb
